# Professional Sales Performance & Insights Dashboard (Portfolio Project)

## 📌 Project Overview
This interactive Sales Dashboard was developed to help business stakeholders track revenue growth, monitor profit margins, and analyze sales performance across different dimensions. The primary objective of this portfolio project is to transform raw sales transaction data into actionable, data-driven business insights that help optimize revenue and identify underperforming markets.

## 🛠️ Tech Stack & Skills Demonstrated
* **Data Cleaning & Transformation:** Utilized Excel Power Query to handle missing values, eliminate duplicates, and standardize transaction dates, currencies, and customer segments.
* **Data Modeling:** Developed a structured data model using advanced Pivot Tables to seamlessly connect sales, products, and regional data.
* **Advanced Formulas:** Applied complex logical and lookup functions including XLOOKUP, VLOOKUP, INDEX-MATCH, SUMIFS, AVERAGEIFS, and nested IF statements for dynamic metrics calculation.
* **Dynamic Dashboard Design:** Built a highly polished, recruiter-friendly executive interface using Custom Charts, Dynamic Slicers, and Timelines for on-demand filtering.

## 📊 Key Sales Insights Delivered
* **Revenue & Profit Trend Analysis:** Tracked monthly and quarterly sales trajectories to spot seasonal trends and growth patterns.
* **Geographical & Regional Performance:** Identified top-performing territories and low-margin zones to support strategic market expansion.
* **Product & Category Deep-Dive:** Analyzed sales volumes and profitability across product lines to uncover the most lucrative business segments.
* **Core KPI Tracking:** Centralized high-level metrics (Total Sales, Total Profit, Profit Margin %, and Quantity Sold) into a single, unified view.

## 📂 How to Explore this Project
1. Download the `.xlsx` file from this repository.
2. Open the file in Microsoft Excel (Enable Editing / Content if prompted).
3. Use the **Slicers/Filters** (Region, Product Category, Year) on the dashboard page to interactively explore the live visualizations.
